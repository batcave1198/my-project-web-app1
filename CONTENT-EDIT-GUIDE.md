# Site Content Editor

Upload your own logo and cover photos to these folders, then tell me what changed. 
I’ll wire them to the site without breaking the design.

## Folders
- `public/logo/` – Put your logo here (`logo.png`, `logo.webp`, `logo.jpg`, or `logo.svg`)
- `public/images/covers/` – Put hero/cover images here

## Cover photos
Rename to these exact names if you want them to show up automatically:

| File | Page |
|---|---|
| `home-hero.jpg` / `.webp` | Home page hero |
| `about-hero.jpg` / `.webp` | About page banner |
| `contact-hero.jpg` / `.webp` | Contact page banner |
| `shop-hero.jpg` / `.webp` | Shop page banner |
| `categories-hero.jpg` / `.webp` | Categories page banner |
| `wishlist-cart-hero.jpg` / `.webp` | Wishlist/Cart (optional) |

## How to use
1. Drop your images in the folders
2. Rename them to match the names above
3. Message me: "Added [filename] for [page]" and I'll apply/update it right away

That's all. Keep the rest of the site as-is.
